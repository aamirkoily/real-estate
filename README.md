# HomeMatch AI · Abu Dhabi

An AI-powered property search for the Abu Dhabi emirate. Buyers describe what they need in plain English (budget, bedrooms, where they work or their children study, freehold or not, must-haves) and HomeMatch AI turns it into precise requirements, filters every listing against them, ranks the best fits and explains each match honestly. It also shows every home on Google Maps with directions.

AI is provided by [Groq](https://groq.com) (free tier) using the `openai/gpt-oss-120b` model.

## How the search works

1. **Understanding the request** (`/api/parse`). The AI extracts structured requirements: areas, distance to a landmark ("near ADGM", "10 minutes from Cleveland Clinic"), budget, property type, bedroom range, ready vs off-plan, freehold (for expats), must-haves vs nice-to-haves, priorities and purpose (living vs investing). Server-side guards stop the AI from inventing requirements the buyer never mentioned (an area, a strict budget, a hard must-have from "would love a…").
2. **Hard filtering with smart relaxation** (`src/search.js`). Homes must meet every hard requirement. If fewer than 6 do, the engine loosens the least important criteria step by step (distance, +10% budget, one missing must-have, similar types, nearby communities, ...) and tells the buyer exactly what was loosened. Freehold is a legal requirement and is never loosened. When nothing matches it explains why (e.g. "Al Ain is outside the freehold zones") and which single change would help.
3. **Ranking**. Remaining homes are scored on priorities, nice-to-haves, purpose and distance; the AI then re-ranks the top 8 and writes a headline, pros and cons for each. Homes that meet every requirement always come first.
4. **Refining**. After a search, typing "cheaper", "add townhouses" or "what about Yas?" refines the current requirements instead of starting over. Each requirement is shown as a chip that can be removed with one click.
5. **Always works**. If the free AI tier is busy, a keyword parser and the rule-based ranking take over, so search never breaks. Results are cached to save tokens.

## Features

- 119 sample listings across 26 communities in 5 regions: Abu Dhabi Island, the islands (Saadiyat, Reem, Yas, Al Maryah, Hudayriyat, Jubail...), mainland suburbs (Al Raha, Al Reef, Khalifa City, MBZ, Masdar...), the Abu Dhabi–Dubai corridor and Al Ain
- 27 landmarks for "near" searches: business hubs, hospitals, universities, schools, malls, the airport and Dubai
- Freehold vs UAE/GCC-nationals-only marked on every home
- Distance and estimated drive time to the buyer's landmark
- Prices in AED, service charges, gross rental yields, monthly cost estimate (20% down, 4.5% over 25 years) and Golden Visa hint
- Google Maps for every home: location, directions from any starting point, and nearby schools, supermarkets, metro, hospitals and beaches
- AI chat about the homes on screen
- Light and dark themes, hover animations, saved homes, mobile friendly

## Getting started

1. Install [Node.js](https://nodejs.org) 18 or newer. There are no npm packages to install.
2. Create your environment file:
   ```bash
   copy .env.example .env
   ```
   Then open `.env` and paste your Groq API key (get one free at https://console.groq.com/keys).
3. Start the app:
   ```bash
   npm start
   ```
4. Open http://localhost:3000

Use `npm run dev` to auto-restart the server when you edit files.

### Optional: interactive results map

Every home already gets an embedded Google Map and directions with no setup. To also show **all results as price pins on one interactive map**, add a Google Maps JavaScript API key to `.env` (`GOOGLE_MAPS_API_KEY`, optional `GOOGLE_MAPS_MAP_ID`). This key is used in the browser by design, so restrict it to your website's address in Google Cloud Console.

## Listing data

The listings are **sample data** generated by `scripts/generate-abu-dhabi.js` from the community profiles in `scripts/abu-dhabi-communities.js` (projects, coordinates, price-per-sqft ranges, freehold status, typical features). To change the data, edit the profiles and run:

```bash
node scripts/generate-abu-dhabi.js
```

This writes `data/listings.json` and `data/communities.json`. Photos come from `data/community-photos.json`: freely licensed Wikimedia Commons photos of each area, credited on every home. Where no good photo of a community exists, a clearly labelled representative Abu Dhabi photo is used.

To use **real listings**, map your feed (agency CRM, portal partner API...) to the same fields and put each listing's own photo in `image.url`. Each listing has: `id`, `title`, `emirate`, `region`, `community`, `project`, `type`, `price` (AED), `beds` (0 = studio), `baths`, `sqft`, `yearBuilt`, `completion` ("Ready" or e.g. "Q4 2027"), `freehold`, `schoolRating`, `walkScore`, `commuteMinutes`, `commuteTo`, `serviceCharge` (AED/year), `rentalYield` (%), `lat`, `lng`, `features`, `description`, `image`.

Landmarks for "near" searches live in `data/landmarks.json`. Listings for the other emirates from the earlier version are kept in `data/archive/other-emirates.json`.

## Keeping your API keys safe

- Keys live only in `.env`, which is listed in `.gitignore`, so they are never committed.
- The Groq key is only used by the server (`src/groq.js`). The browser never sees it.
- The server listens on `127.0.0.1` only, so other devices on your network can't use your quota.

## Project structure

```
server.js                      HTTP server: static files + JSON API
src/
  env.js                       tiny .env loader
  errors.js                    HttpError (user-safe error messages)
  groq.js                      Groq API client (JSON mode, rate-limit retry)
  listings.js                  data loading, AED/mortgage/distance helpers, compact AI descriptions
  search.js                    requirements, keyword parser, hard filters, relaxation, scoring
  recommend.js                 AI request understanding, AI ranking, chat, caching
scripts/
  abu-dhabi-communities.js     community profiles used to generate sample data
  generate-abu-dhabi.js        writes data/listings.json and data/communities.json
data/                          listings, communities, landmarks, photos
public/                        index.html, styles.css, app.js
```

## API

| Method | Path             | Body                              | Returns                                                         |
| ------ | ---------------- | --------------------------------- | --------------------------------------------------------------- |
| GET    | `/api/health`    |                                   | AI status, model name, Google Maps settings                     |
| GET    | `/api/listings`  |                                   | listings + communities, regions, landmarks, vocabularies, loan  |
| POST   | `/api/parse`     | `{ query, current? }`             | requirements, interpretation, follow-up question                |
| POST   | `/api/recommend` | requirements                      | top picks with AI explanations, more matches, relaxation notes  |
| POST   | `/api/chat`      | `{ messages, listingIds, prefs }` | assistant reply                                                 |

## Notes

- Prices, yields and details are realistic but invented; freehold zones reflect the general rules and should be confirmed with ADREC or a registered agent.
- Fees, mortgage rules and Golden Visa eligibility change over time. The app gives estimates only.
- The Groq free tier allows about 8,000 tokens per minute (roughly two searches a minute). The app retries briefly and falls back to keyword search when it's busy.
- AI output can be wrong. This app is not financial or legal advice.
